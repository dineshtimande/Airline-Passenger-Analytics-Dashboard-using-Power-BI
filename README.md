# Airline-Passenger-Analytics-Dashboard-using-Power-BI

## 🧭 Project Overview

This Project features a robust Power BI dashboard designed to visualize and analyze airline passenger data. The dashboard uncovers valuable insights into passenger demographics, ticket revenue distribution, travel destinations, seat class preferences, and booking statuses. Both business and data teams can utilize this project to better understand travel patterns, improve sales strategies, and enhance passenger experience.

## ⚙️ Features

- **Total Passengers & Revenue:** Track total passengers and cumulative ticket price.
- **Source and Destination Filters:** Quickly analyze by departure and arrival cities.
- **Interactive Charts:** Includes pie charts, bar charts, and trend lines for:
  - Gender & Age group distributions
  - Booking status (Confirmed, On Hold, Cancelled)
  - Ticket price analysis by seat class and individual passengers
- **Tabular Data View:** Inspect all details for individual passengers including name, age, gender, route, class, and status.

## 📋 Dataset Fields

- PassengerID, Full Name, Age, Gender
- FlightNumber, Departure, Destination
- TicketPrice, SeatClass, Status
- Age Group


## 💡 Insights Derived

- Young adults (25–35) travel most frequently.
- Business class brings in maximum revenue.
- Female bookings are higher in this demo data.
- Booking confirmations significantly exceed cancellations.

## 🧰 Tools and Technologies

- 📊 Power BI : Dashboard creation and visualization.
- 🧠 DAX / M Language: Calculated columns, measures, logic modeling.
